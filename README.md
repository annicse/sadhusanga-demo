# Sadhusanga Setlists
## This is a public demo version of a private app

Sadhusanga Setlists is an offline-first band setlist management application built with Next.js.

## Features

- **Setlist Management:** Create, read, update, and delete setlists.
- **Offline Capabilities:** Works seamlessly without an internet connection using Progressive Web App (PWA) features.
- **Dark Mode:** A sleek, modern dark theme for optimal low-light viewing (e.g., during gigs).
- **Responsive Design:** Accessible and usable across devices.

## Tech Stack

- **Framework:** [Next.js](https://nextjs.org/)
- **Database:** Neon & Prisma
- **Styling:** Tailwind CSS & shadcn/ui
- **Icons:** Lucide React

## Getting Started

First, install the dependencies:

```bash
npm install
# or
yarn install
# or
pnpm install
```

Then, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
